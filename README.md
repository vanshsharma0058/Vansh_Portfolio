# Vansh Sharma Portfolio

A Next.js App Router portfolio built around the approved “Ideas in Motion” direction.

## Run locally

```bash
npm install
npm run dev
```

The production build uses `npm run build`; serve it with `npm start`.

## Before deployment

The metadata intentionally omits a canonical URL and social preview image until a production domain is supplied. Sitemap and robots URLs are generated from the request host.

The source materials did not include a resume or project screenshots. Project visuals are labeled illustrative studies, and the resume is not offered as a download. The Softiwa technology stack is omitted until the conflicting source descriptions are confirmed.
